MCSA — Cyber Edition

جزوه آموزشی Windows Server، شبکه و زیرساخت؛ با ظاهر سایبری و تمرکز روی یادگیری عملی.

[ گردآورنده: دانیال ]

فصل ۱ — آشنایی با Windows Server و مفاهیم زیرساخت

1.1 — Windows Server چیست؟

Windows Server سیستم‌عامل مایکروسافت برای ارائه و مدیریت سرویس‌های شبکه، کاربران، کامپیوترها و منابع سازمانی است.

نکته: در محیط‌های سازمانی، Server معمولاً یک یا چند Role و Service مشخص را ارائه می‌دهد.

1.2 — Server و Client

Server سرویس ارائه می‌کند و Client از سرویس‌ها استفاده می‌کند. یک سیستم می‌تواند بسته به سناریو نقش‌های متفاوتی داشته باشد.

1.3 — IP Address

نمونه IPv4:

192.168.10.10

1.4 — Subnet Mask

IP:   192.168.10.10
Mask: 255.255.255.0
CIDR: /24

1.5 — DNS

DNS نام را به IP و در برخی سناریوها IP را به نام تبدیل می‌کند. در Active Directory نقش بسیار مهمی دارد.

1.6 — DHCP

DHCP تنظیمات شبکه مانند IP، Subnet Mask، Gateway و DNS را به‌صورت خودکار به Client می‌دهد.

1.7 — Domain و Active Directory

Domain محیط مدیریت متمرکز کاربران و سیستم‌هاست و AD DS سرویس اصلی مایکروسافت برای مدیریت هویت و منابع Domain است.

1.8 — Domain Controller

سروری که AD DS روی آن نصب شده و وظایف مربوط به احراز هویت و مدیریت Domain را انجام می‌دهد.

1.9 — PowerShell

Get-NetIPAddress
Get-NetAdapter
Get-ComputerInfo
Get-Service
Get-Process
Clear-Host

1.10 — ابزارهای پایه شبکه

ipconfig /all
ping 192.168.1.1
nslookup google.com
tracert google.com

1.11 — سناریوی عملی

Server: DC01
IP:     192.168.10.10
Mask:   255.255.255.0
DNS:    192.168.10.10

ابتدا نام سیستم و تنظیمات شبکه را بررسی کنید:

hostname
ipconfig /all
ping 192.168.10.1

تمرین فصل ۱

  1. تفاوت Server و Client را توضیح دهید.
  2. برای 192.168.10.25 با Mask 255.255.255.0، Network را مشخص کنید.
  3. وظیفه DNS چیست؟
  4. DHCP چه اطلاعاتی به Client می‌دهد؟
  5. Workgroup و Domain را مقایسه کنید.
  6. دستورات hostname، ipconfig /all و Get-NetIPAddress را اجرا و خروجی را بررسی کنید.

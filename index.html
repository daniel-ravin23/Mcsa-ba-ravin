چطور استفاده کنیم؟

  • از منوی سمت راست فصل مورد نظر را انتخاب کنید.
  • محتوای هر فصل را با دقت بخوانید و دستورات را در محیط Lab تمرین کنید.
  • در پایان هر فصل، تمرین تعاملی را حل کنید تا امتیاز بگیرید.
  • پیشرفت و امتیاز شما به‌صورت خودکار در مرورگر ذخیره می‌شود.
  • پس از اتمام فصل‌ها، آزمون نهایی جامع را بدهید.

محیط Lab پیشنهادی

برای تمرین عملی این ساختار را در Hyper-V یا VirtualBox پیاده‌سازی کنید:

  • DC01 — Windows Server (Domain Controller) — IP: 192.168.10.10/24
  • SRV01 — Windows Server (Member Server) — IP: 192.168.10.20/24
  • PC01 — Windows 10/11 Client — IP: DHCP یا ثابت
  • Gateway / DNS: 192.168.10.10
نکته: همه تمرین‌ها روی همین Lab قابل اجرا هستند. قبل از شروع، Snapshot بگیرید.

درباره این جزوه

این محتوای آموزشی مستقل برای یادگیری مفاهیم پایه تا پیشرفته Windows Server و آمادگی ذهنی برای مسیر MCSA طراحی شده است. متن اختصاصی دوره‌های تجاری را بازتولید نمی‌کند و تمرکز روی درک عملی و تمرین دارد.

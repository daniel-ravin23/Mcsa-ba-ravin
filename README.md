# MCSA Cyber Notes — نسخه حرفه‌ای تعاملی

**گردآورنده: دانیال — فراگیر آکادمی راوین**

جزوه کامل و تعاملی ۱۲ فصل Windows Server / MCSA با تم سایبری حرفه‌ای.

## ویژگی‌ها

- تم Cyber / Hacker حرفه‌ای با انیمیشن‌های ظریف
- ۱۲ فصل کامل با ساختار مرتب و توضیحات دقیق
- تمرین تعاملی برای هر فصل با بررسی خودکار
- سیستم امتیاز و نمره
- نمایش درصد پیشرفت و امتیاز کل
- آزمون نهایی جامع (۱۵ سؤال)
- ذخیره پیشرفت داخل مرورگر (localStorage)
- کاملاً مناسب موبایل و دسکتاپ
- ظاهر حرفه‌ای بدون شلوغی

## نحوه استفاده

فقط فایل `index.html` را در مرورگر باز کنید. نیاز به سرور ندارد.

- SRV01: Member Server — 192.168.10.20/24
